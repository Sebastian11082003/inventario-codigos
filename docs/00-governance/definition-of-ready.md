# Definition of Ready

Una historia de este producto está Ready cuando cumple [definition-of-ready.md del OS](https://github.com/Sebastian11082003/ai-engineering-os/blob/main/checklists/definition-of-ready.md) del OS y, además:

- El criterio dice si el paso usa la cámara trasera o el respaldo manual.
- El error de cámara (permiso, sin cámara, sin HTTPS) tiene un resultado visible en español.
- Si toca el Excel, nombra las columnas del contrato.
