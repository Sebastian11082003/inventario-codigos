# Manual de uso

1. Abre la dirección `https://` en el teléfono. La cabecera es papaya y dice Inventario.
2. Pulsa **Escanear con la cámara**. Si la lista está vacía, el botón está en la cabecera. Si ya hay productos, queda fijo abajo. La indicación es «Mantén el código quieto.» La primera lectura cambia esa frase a «Ya lo veo, no lo muevas.» El número se acepta al segundo acuerdo seguido, no al primero.
3. Permite la cámara cuando el navegador lo pida. Se usa la de atrás. Deja el código dentro del recuadro. La línea naranja es una guía: la lectura también mira arriba y abajo de esa línea, y una botella de lado.
4. Si el teléfono puede iluminar, la barra del visor muestra **Flash**, a la derecha y sin tapar el recuadro. Púlsalo para encender la luz y otra vez para apagarla. El botón pasa a papaya cuando la luz está encendida. Si no aparece, esa cámara no ofreció flash. En una botella curva el reflejo puede borrar las barras: se puede leer con el flash apagado. Cerrar el visor apaga la luz.
5. Apunta al código hasta que aparezca el número. Pulsa **Usar este código**.
6. Escribe el nombre que tú le pones, elige la categoría y la unidad: **Cantidad**, **kg** o **Gramos**. La unidad por defecto es Cantidad. En kg y gramos puedes escribir decimales, por ejemplo `0,5` kg o `250` g. En cantidad basta un entero; si escribes un decimal, no se pierde. El precio puede quedar vacío.
7. Pulsa **Guardar producto**. El producto queda en la lista de este teléfono aunque cierres la pestaña.
8. Corrige con − y + en la bandeja de la tarjeta, o abre el producto.
9. En la lista, el número muestra la unidad al lado: cantidad, kg o gramos. Pulsa **Exportar Excel**. Cada fila trae Código, Nombre, Categoría, Cantidad y Unidad (`cantidad`, `kg` o `g`), y después Precio y Notas. Si la lista está vacía, esa acción está apagada.

Si la frase no cambia de «Mantén el código quieto.», recarga la página. GitHub Pages puede guardar el HTML anterior unos diez minutos; el JavaScript nuevo tiene otro nombre y llega cuando el HTML está fresco.

Si la cámara no puede usarse, **Escribir código** cumple el mismo camino a partir del paso 6. Un campo vacío marca el error en rojo junto al campo y no guarda.

Categorías: desde la lista, **Categorías**. Las cuatro iniciales se pueden renombrar.

El archivo no se envía a ningún servidor. Quien tenga el teléfono puede ver la lista.
