# Manual de uso

1. Abre la dirección `https://` en el teléfono. La cabecera es papaya y dice Inventario.
2. Pulsa **Escanear con la cámara**. Si la lista está vacía, el botón está en la cabecera. Si ya hay productos, queda fijo abajo. Mantén el código quieto hasta que se confirme.
3. Permite la cámara cuando el navegador lo pida. Se usa la de atrás.
4. Apunta al código hasta que aparezca el número. Pulsa **Usar este código**.
5. Escribe el nombre, elige categoría, cantidad y unidad. El precio puede quedar vacío.
6. Pulsa **Guardar producto**. El producto queda en la lista de este teléfono aunque cierres la pestaña.
7. Corrige con − y + en la bandeja de la tarjeta, o abre el producto.
8. Pulsa **Exportar Excel** y lleva ese archivo al punto de venta. Si la lista está vacía, esa acción está apagada.

Si la cámara no puede usarse, **Escribir código** cumple el mismo camino a partir del paso 5. Un campo vacío marca el error en rojo junto al campo y no guarda.

Categorías: desde la lista, **Categorías**. Las cuatro iniciales se pueden renombrar.

El archivo no se envía a ningún servidor. Quien tenga el teléfono puede ver la lista.
